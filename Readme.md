# 🌐 laksec — Web3 & Blockchain Security Journey by Lakshman

Welcome to **jpstacker/CryptoBunker**, my personal repository for exploring Web3 security, smart contract auditing, decentralized application vulnerabilities, and blockchain cybersecurity.

---

## 👨‍💻 About Me

I'm **Jadapalli Lakshmaiah (LAKSHMAN)**, a cybersecurity enthusiast from India diving deep into the world of Web3 and blockchain security. Here, I document my hands-on experiments, audit practices, vulnerability research, and learning resources — building knowledge for myself and the community.

---

## 📒 What You’ll Find Here

- **Smart Contract Audits**  
  Notes on common vulnerabilities (reentrancy, overflow/underflow, access control), testing methodologies, and audit checklists.
- **Web3 Security Research**  
  Findings related to DeFi exploits, wallet security, bridge attacks, and governance manipulation.
- **Payloads & Scripts**  
  Proof-of-concept scripts for testing, fuzzing tools, and exploit examples in Solidity/Vyper.
- **Learning Logs**  
  Regular entries tracking progress, CTF write-ups, and challenge takeaways.
- **Resources & Tools**  
  Curated lists of audit platforms, practice labs, essential reading, and security tooling for Web3.

---

## 🗂️ Structure

- `smart-contract-vulns.md` — Smart contract vulnerabilities and exploitation techniques
- `web3-ecosystem-attacks.md` — DeFi, bridges, oracles, and wallet security issues
- `tools-setup.md` — Slither, MythX, Foundry, Hardhat, and security plugins
- `audit-log.md` — Timeline of practice audits and real-world case studies
- `resources.md` — Learning platforms, CTFs, blogs, and Web3 security references
